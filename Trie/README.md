# Trie

Implementation of a Trie (Prefix Tree).

## Operations

- insert(word)
- search(word)
- startsWith(prefix)

## Complexity

| Operation | Time |
|-----------|------|
| Insert | O(L) |
| Search | O(L) |
| StartsWith | O(L) |

L = length of the string.

## Applications

- Prefix search
- Dictionary
- Auto-complete
- Word Search II
- Maximum XOR (Binary Trie)
